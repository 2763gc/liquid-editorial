# Liquid Editorial v2 · 艺术方向

> 一句话：**墨落于水，字成于纸。**
> Liquid Editorial 是一方会流动的墨池。文章是浮在墨上的纸笺；墨在池里流动，字在纸上凝结。

站名里的 *Liquid* 和 *Editorial* 第一次真正合在了一起：**流动的是墨，凝固的是字**。东方水墨的「晕、染、洇、皴」做动态语言，瑞士网格与超大衬线做版式骨架，朱砂只作为「印」出现。

---

## 1. 为什么不是「活版印刷」

上一版方向（印刷工坊）在视觉上只能落成网点、角线、套准这类小细节，撑不起「视觉盛宴」，而且当时的转场用一整张朱砂纸覆盖全屏——这正是红色闪屏的来源。水墨方向有三个好处：

1. **它本身就是动的。** 墨在水里的扩散、回旋、沉淀，天然是动画素材，而且每一帧都不同。
2. **它和品牌名同源。** Liquid Editorial = 墨池上的编辑部。
3. **它让朱砂回到正确的位置。** 朱砂不再铺满屏幕，只作为印章、墨的边缘色、当前态的一点红。

## 2. 母题

| 母题 | 含义 | 出现在 |
| --- | --- | --- |
| 墨池 | 首页是一方可以搅动的墨池（实时流体模拟），纸笺浮在上面 | 首页首屏 |
| 墨滴 | 一滴墨从按钮处洇开 | 目录页（菜单） |
| 凝字 | 标题从墨的扰动中沉淀、收拢成清晰的字 | 页面标题入场、刊头 |
| 水墨封面 | 每篇文章按 slug 生成一幅独一无二的水墨（山、云、晕、皴） | 卡片、文章头图、列表悬停 |
| 朱砂印 | 期号、点赞、当前态 | 封面印章、「阅」字点赞、导航圆点 |
| 纸 | 四时光照下的同一张宣纸；纤维、洇边 | 背景与质感层 |

## 3. 动效语汇

| 语汇 | 隐喻 | 表现 | 实现 |
| --- | --- | --- | --- |
| 落墨 Drop | 墨滴落纸 | 从按钮处向外洇开，边缘不规则 | 噪声扰动过轮廓的墨迹遮罩（CSS mask），只用于目录页 |
| 凝字 Settle | 墨沉淀成字 | 位移扰动由强到零、模糊收拢 | SVG feTurbulence + feDisplacementMap，GSAP 驱动 scale |
| 搅墨 Stir | 指尖搅动墨池 | 光标与拖拽在墨池里留下涡流 | WebGL 稳定流体（平流、涡量、压力投影） |
| 洇 Bleed | 墨沿纸纤维渗开 | 悬停时墨色从边缘洇入 | CSS mask + 噪声遮罩 |
| 钤印 Stamp | 盖章 | 朱砂印带着轻微旋转压下，回弹 | transform + 缓动 outBack |

节奏：进入用 outExpo，离开用 inQuart 且更快；同组错峰 ≤ 60ms。

页面之间**不做转场动画**：点击后新页面一就绪就直接换上（悬停 100ms 时已预取数据，多数情况下几乎是瞬时的）。动效只留在页面内容上——标题凝字、条目揭示、墨池与悬停——不在跳转这一步拦住读者。

## 4. 红色闪屏的根因与修复

- **现象**：点击导航后约 0.45s 无反应，随后整屏朱砂色停留约 0.65s 再硬切。
- **根因**：Nuxt 在 `<Suspense>` 中先完成新页面的数据加载，才触发 `<Transition>`；于是 `onLeave` 与 `onEnter` 几乎同时被调用，`onLeave` 中纸张补间的 `overwrite: true` 杀掉了 `onEnter` 的离场补间，纸张停在全屏位置。纸张本身是不透明的全屏朱砂色，最后由 `visibility: hidden` 硬切掉。
- **修复**：去掉页面转场。一度改成路由守卫驱动的「落墨 → 切换 → 洗墨」，实际使用中这一步只是拖慢跳转、打断阅读，于是整段删除。现在路由切换时只做看不见的工作：预取数据、复位或恢复滚动、把焦点交给新页面的 h1（返回时交还给原来点击的链接）。

## 5. 分页主角

| 页面 | 主角 |
| --- | --- |
| 首页 | 墨池：实时流体 + 浮动纸笺画布；标题以差值混合「刻」在墨上，墨流过时字反白 |
| 文章 | 水墨头图 + 凝字标题；朱砂「阅」印点赞；毛笔进度线 |
| 文章索引 | 悬停条目，水墨封面带惯性跟随光标、从边缘洇开 |
| 专栏 | 书脊（竖排书名、按篇数计算厚度） |
| 项目 | 字模样张 |
| 归档 | 时间之河：横向滚动，年份是水中的倒影 |
| 菜单 | 墨从菜单按钮处晕开成一页目录 |
| 404 | 落字：活字掉进墨池 |

## 6. 降级

- `prefers-reduced-motion` 或站内开关：墨池静止为一幅水墨画；凝字、揭示直接显示；目录页直接出现。
- 低档设备 / 无 WebGL2：墨池改为静态生成水墨。
- 触屏：墨池随手指搅动，但分辨率减半；无自定义光标。
- 页面不可见时 ticker 休眠，WebGL 停止绘制。

## 7. 后台 · 编辑部的案头

后台不追求炫技，追求工具的精致：与前台共用全部 Token（色板、四时光照、字体、缓动），明暗偏好独立（默认夜间），信息密度更高，动效时长是前台的一半，页面之间不做转场。

| 部分 | 做法 |
| --- | --- |
| 版面 | 案头是 surface，每块面板是一张纸（bg + 发丝线），不靠阴影分层；控件 3px 直角，面板 4px |
| 侧栏 | 栏目带编号（§ 00…06），选中项左侧一道墨线，在条目间弹簧滑动；`[` 收成 64px 窄栏并记住偏好 |
| 顶栏 | 衬线的当前栏目名 + 面包屑；接口连通状态（每分钟探测，断开时亮红点）；检索入口 |
| 键盘 | ⌘K 命令面板（前往、动作、按标题直达特稿，命中字下划朱砂线）；`g d/p/t/m/l/s` 跳转；`n` 新建；列表里 `j/k` 移动、回车编辑、`p` 发布或撤回、`o` 前台查看、`/` 搜索 |
| 反馈 | 提示是一张小纸条，左侧钤「成 / 误 / 注」小印；确认框钤「问 / 删」；骨架屏是浅网点校样，不用灰色圆角块 |
| 仪表盘 | 发丝线分隔的数字栏；写作日历（最近 53 周，墨点越浓越大，最浓的日子钤朱砂方印）+ 首发 / 修订 / 落笔 / 最长连续 |
| 编辑器 | CodeMirror 6（按需加载，墨色语法高亮）；预览由服务端同一个渲染器输出，浏览器不下载 Shiki；改动每秒存进本机 IndexedDB，每两分钟与每次保存留一版修订（最多 30 版）；本地草稿比服务器新时提示恢复；版式卡用该模板的水墨构图，设色是八种传统颜料 |
| 登录 | 品牌面板是一方夜色墨池，指尖划过搅起银墨；启用两步验证后第二步「再验一道」，验证码等宽大字距、满 6 位自动提交，可改用恢复码 |
| 安全 | § 06：两步验证的二维码在本地生成，永远是白纸黑墨（深色模式下照样好扫），四角一对套准线；恢复码只显示一次；改密强度是四段墨条，规则与服务端同一套；会话一台设备一行，本机左侧一道墨线；操作留痕按级别筛选；30 分钟无操作自动退出，最后一分钟底部提示 |
| 状态色 | 只用一个小方点 + 字；朱砂只给「发布」这类定稿动作 |
