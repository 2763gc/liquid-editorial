# Liquid Editorial v2 · 全面升级任务书（提示词）

> **用法**：在仓库根目录新开一个 Claude Code 会话，把下面分隔线以下的全部内容粘贴进去。
> 任务量很大，提示词要求按阶段推进，每个阶段结束都会停下来等你确认，不会一口气改完全站。

## 0. 你的角色与目标

你同时担任这本个人技术刊物《Luntrix's Editorial》的**艺术总监、动效导演和前端负责人**。

任务是对整个网站做一次全面升级，覆盖功能、动效、视觉展示和交互体验。全站的主题是三个词：**精致、创意、艺术**。

- **精致**：每个像素、每一帧都经得起放大看。间距、字重、缓动曲线、时长和错峰都有依据，没有一处是随手定的。
- **创意**：用一个独有的隐喻统领全站（见第 2 节），让访客即使不看站名，也认得出这是谁的刊物。
- **艺术**：它首先是一份让人愿意读完的刊物，其次才是一件作品。动效服务于阅读节奏，不抢正文的戏。

**这不是推倒重来。** 现有的 Liquid Editorial 体系（纸与墨、瑞士网格、超大衬线标题、朱砂强调色、四时光照）是这次升级的地基，在它之上把每一处做到极致，并补齐还没做的签名动效。

## 2. 创意总纲：「活版印刷工坊」（The Living Press）

站点不是一组页面，而是**一台为每位读者实时印刷当期刊物的印刷机**。

现有元素已经在说这门语言：开场的「压印」、No. 042 期号、Vol. 2026、Erratum 404、「印刷机暂时卡住了」。v2 要把它变成**所有视觉与动效决策的唯一来源**。

### 2.1 视觉母题

| 母题 | 在站点中的含义 | 主要用在 |
| --- | --- | --- |
| 纸 | 页面底色与纤维质感。四时光照就是同一张纸在不同光线下的样子 | 背景、质感层 |
| 墨 | 唯一会「流动」的材质：悬停时墨洇开，光标是一滴墨 | 悬停、选中、光标 |
| 朱砂 | 专色和印章。克制使用 | 强调、印章、转场 |
| 套准与裁切标记 | 印刷校准用的十字和角线 | 刊头四角、图片角、加载态 |
| 网点 | 半色调 | 图片占位、生成式封面、友链头像 |
| 活字 | 可变字体的字重轴就是「压力」 | 首页标题、404、命令面板 |
| 装订 | 书脊、合订本 | 专栏、归档 |
| 校样 | 打样稿 | 骨架屏、开发用网格叠加层（按 `G` 键） |

### 2.2 动效语汇表

**全站每一个动画都必须归入下面某一个语汇。** 不属于任何语汇的动画一律删掉。

| 语汇 | 物理隐喻 | 视觉表现 | 实现要点 | 用于 |
| --- | --- | --- | --- | --- |
| 压印 Impress | 铅字压到纸上 | 字重从细到目标值，scale 1.015→1，极短 | Fraunces `wght` 轴 + transform | 标题入场、按下、点赞 |
| 走纸 Feed | 纸张穿过滚筒 | 整面自下而上平移，前沿带一条墨线 | transform + clip-path | 路由转场、菜单 |
| 套准 Register | 多色版对齐 | 墨层与朱砂层从 2–6px 的错位收拢到对齐 | 两层 transform | 刊头、封面入场、悬停 |
| 晕染 Bleed | 墨在纸纤维里洇开 | 遮罩边缘不规则地扩散 | 预渲染噪声遮罩，或 WebGL 噪声 | 图片和封面悬停、主题切换的边缘 |
| 翻折 Fold | 折页 | 小角度 rotateX（≤ 12°）加明暗变化 | 3D transform | 折叠与展开 |
| 揭版 Lift | 印好的纸从版上揭起 | 上层内容上移，揭开下层 | sticky 或 fixed + transform | 页脚、沉浸式头图 |
| 落字 Drop | 活字落进字盘 | 刚体下落与碰撞 | matter.js，只在 404 页按需加载 | 404 |

### 2.3 克制原则

1. **每页只有一个「主角」签名动效**，其余都是配角，而且时长更短。
2. **隐喻是方法，不是装饰。** 不画齿轮、滚筒、印刷机插画，不大面积铺拟物纹理。
3. **数值上限**：
   - 朱砂面积不超过视口的 5%（转场遮罩除外）。
   - 套色错位不超过 6px，持续不超过 300ms。
4. **读正文时一切安静。** 正文区没有循环动画、视差、形变，也没有光标拖尾。

## 3. 不可妥协的约束

### 3.1 设计

- **只用 Token。** 颜色、阴影、圆角、时长、缓动全部来自 `tokens.css`，页面里不写硬编码色值。审计点名过的例子：
  - `admin.vue` 的 `bg-[#0C0C0D]`
  - `about.vue` 的 `rounded`
  - 画布项目卡的 `#111113` 和 `#F5C451`
- **复用已有组件。** 优先用 `components.css`、`UiPageMasthead`、`UiSegmented`。新的视觉语汇先进入系统，再进入页面。
- **遵守 PRD 2.1 的禁区**：
  - 圆角卡片 + 投影 + 紫蓝渐变的 SaaS 风格
  - 组件库外观
  - emoji 图标
  - 居中堆叠的 Hero
  - 为动而动
- **分隔和阴影。** 优先用发丝线分隔；阴影只给浮层。

### 3.2 工程

- **只动画合成层属性。** 只对 transform 和 opacity 做动画；clip-path 和 filter 只允许短时使用。不动画 width、height、top、left、padding（B44 里的 `padding-left` 悬停动画要改掉）。
- **全站只有一个 rAF。** 一律用 `gsap.ticker.add`，不再新开 `requestAnimationFrame` 循环。
- **防泄漏。** 组件内的动画一律放进 `gsap.context()`，卸载时 `revert()`，ScrollTrigger 不能泄漏。
- **SSR 一致。** 依赖时间、随机数或窗口尺寸的内容，要么只在客户端渲染，要么在 bootScript 里确定。控制台不能有任何 hydration 警告（B27）。
- **禁用 JS 时全站可读。** 开场遮罩不能永久盖住页面（B26）。
- **TypeScript。** strict 模式，不新增 `any`。
- **新依赖要论证**：说明 gzip 体积、是否进入首屏、有没有替代方案。
  - 可以升级到 GSAP 3.13+，其 SplitText、Flip、CustomEase 等插件已免费。
  - three.js / TresJS 整包不进首屏。

### 3.3 性能预算（PRD 11.1）

| 指标 | 目标 |
| --- | --- |
| 首屏 JS | ≤ 180 KB gzip，不含 WebGL 和编辑器分包 |
| WebGL 分包 | ≤ 200 KB gzip（本次目标 < 30 KB），只在需要的页面加载 |
| LCP | 文章页 ≤ 2.0 s，首页 ≤ 2.5 s |
| CLS | ≤ 0.05 |
| INP | ≤ 200 ms |
| Lighthouse 移动端 | 性能：文章页 ≥ 90、首页 ≥ 80；无障碍 ≥ 95；最佳实践 ≥ 95；SEO 100 |
| 帧率 | CPU 4 倍降速下，滚动、拖拽、转场持续 ≥ 55 fps，交互期间没有超过 50 ms 的长任务 |

### 3.4 降级（PRD 3.6）

- **设备分三档**（高 / 中 / 低）：用 `hardwareConcurrency`、`deviceMemory`、`saveData`、指针类型和首帧耗时启发式判断。
- **减弱动效**（系统设置或站内开关）：关闭平滑滚动、视差、形变和光标动画；转场改为 200 ms 淡入淡出。
- **触屏设备**：不渲染自定义光标和磁吸；悬停效果改为按压反馈。
- **页面不可见时**：暂停 ticker 和 WebGL 渲染。

## 4. 全局系统升级（先做，所有页面都依赖它）

### 4.1 Token 2.0

- **动效数据单一来源。** 合并 `composables/motion/tokens.ts` 和 CSS 中的两份动效数据。
  - 用 CustomEase 注册与 CSS 同名的缓动（outExpo、inOutQuart、outBack、spring）。
  - GSAP 代码里不再出现 `power3`、`elastic` 这类散落的字符串（B47）。
- **色彩改用 OKLCH 定义。** 四个时段之间用 OKLCH 插值，过渡更自然。
- **新增语义 Token**，例如：
  - `--register-offset`、`--ink-spread`
  - `--paper-fiber-opacity`
  - `--light-angle`、`--light-warmth`
  - `--dur-impress`（建议约 240 ms）
- **强调色对比度。** 文章用 `accent_color` 覆盖强调色时，自动推导 `--color-accent-ink`，并检查它在纸色和墨色底上的对比度；达不到 WCAG AA 时自动调整明度。

### 4.2 字体与中文排版

- **自托管字体，停用 Google Fonts。** Google Fonts 在国内不可达，阻塞渲染约 2.3 秒。
  - Fraunces、Inter、JetBrains Mono 用子集化的 woff2 可变字体。
  - 中文用 cn-font-split 切片。
  - 预加载首屏标题用到的字。
  - 用 `size-adjust` 和 `ascent-override` 对齐回退字体的度量，消除字体切换造成的 CLS。
- **界面中文。** 目前落到了微软雅黑。补上 Noto Sans SC，或者调好系统黑体的度量。
- **中文排版细节**（新特性一律作为渐进增强）：
  - 标点挤压：`text-spacing-trim`
  - 中西文间距：`text-autospace`，或由渲染器在服务端插入细空格
  - 避头尾
  - 标题用 `text-wrap: balance`，正文用 `text-wrap: pretty`
- **Fraunces 的轴怎么用。**
  - `opsz` 随字号自动变化。
  - `SOFT` 和 `WONK` 是字体的「性格」，只用在展示级标题上。
  - Fraunces **没有 `wdth` 轴**。PRD M5 要求的「滚动速度影响字宽」用 `SOFT` 加字距来模拟。

### 4.3 动效引擎

- **`useMotion()`**：暴露设备档位、是否减弱动效、是否触屏、已注册的缓动，并提供 `ctx(scope, fn)` 包装 `gsap.context`。
- **Pinia `useTransitionStore`**：管理转场状态（idle / leaving / entering）、来源元素，以及滚动位置和画布视角的快照。
- **插值与帧率无关**：所有手写的 lerp 都改成 `1 - Math.pow(1 - k, dt * 60)`，保证 60 / 120 / 144 Hz 下手感一致。
- **悬停意图**：
  - 进入前有约 60 ms 的防抖。
  - 进入慢、离开快（约 500 ms 进，300 ms 出）。
  - 随时可以中断：用 CSS transition，或 GSAP 的 `overwrite: 'auto'`。
- **不再掩盖空目标**：删掉 `gsap.config({ nullTargetWarn: false })`，把真正的空目标修掉。
- **样张页**：把 `/dev/motion` 升级为「动效样张」。每个语汇一张样张，可以回放、可以调参数，并显示 CPU 4 倍降速下的帧率计。

### 4.4 页面转场（PRD 3.5 + 走纸）

- **默认转场**：
  1. 一张朱砂色的纸自下而上「走纸」盖住页面（前沿有一条 1px 墨线和 2px 套色错位）。
  2. 切换路由。
  3. 纸继续上移离开，新页面的标题在纸的尾缘之后逐行「压印」出现。
  - 总时长 ≤ 900 ms。
  - 转场期间锁定点击和滚动。
  - 用 Nuxt `pageTransition` 的 JS 钩子（onLeave / onEnter）实现。
- **进入文章（M2 共享元素转场）**：卡片上的期号「No. 042」、标题和生成式封面作为共享元素，飞到文章头部的位置；返回时逆向收回原位。
  - 优先用 View Transitions API（Nuxt `experimental.viewTransition` 配合 `view-transition-name`）。
  - 浏览器不支持时退回 GSAP Flip。
- **可中断**：转场途中再点导航，不排队，直接改道去新目标。
- **返回上一页**：恢复滚动位置和首页画布的视角。
- **焦点**：转场后焦点落到新页面的 h1，让屏幕阅读器播报；返回时焦点回到原来点击的链接。
- **例外**：SSR 首屏不播放转场；减弱动效模式下改为 200 ms 淡入。

### 4.5 四时光照 2.0

- **从四档变为连续。** 每个时段内部，按分钟在相邻两档之间做 OKLCH 插值（比如 16:30 已经带一点暮色），每 5 分钟校准一次。单次变化肉眼察觉不到，但一整天里光线真实地在流动。
- **窗光。** 叠加一层极淡的光照渐变：
  - 角度按本地时间估算太阳位置，不请求定位权限。
  - 晨偏冷，暮偏暖。
  - 夜里改成「台灯」：光标附近的极淡暖光，只在高档设备、只在正文以外的区域出现。
- **首次加载**：按 PRD 2.2，颜色用 2 秒缓动过渡到当前时段。用 `@property` 注册颜色变量来实现，不能引起 hydration 不一致或 CLS。
- **主题切换**：保留现有的圆形扩散，把边缘改成「晕染」式的不规则边缘。
- **P2**：Favicon 随时段切换。

### 4.6 质感层

- **胶片颗粒改为纸张纤维。**
  - 预渲染 2–3 张小尺寸噪点贴图，合计 ≤ 20 KB。
  - 用 `steps()` 切换贴图位置，不要逐帧重绘。
  - 强度随时段变化，正文区更淡。
- **全局细节统一定制**：选中色、滚动条、焦点环（朱砂色、带套准标记的样式）、`caret-color`、placeholder、`::marker`、`<kbd>`（做成铅字样式）。
- **新组件 `<UiCropMarks>`**：裁切和套准标记，用在刊头四角、图片角和加载态。

### 4.7 光标 2.0（只在桌面端）

- **保留**现有的圆点 + 圆环。
- **新增语境**：
  - 代码块上显示「复制」，外链上显示「↗ 外链」，图片上显示「放大」。
  - 拖拽画布时，圆环按速度方向拉伸成椭圆，最大 1.6 倍，像墨滴被甩出去。
  - 选中文字时隐藏圆环。
- **磁吸按 PRD 的规定**：光标进入 80px 半径就开始吸引。现在只在元素边界内才生效（B15）。复位用 Token 里的缓动。

### 4.8 滚动

- **Lenis**：参数按设备档位微调；锚点跳转、浏览器前进后退都要和 Lenis 协调好。
- **M8 速度形变**：列表和图片随滚动速度做 skewY，最大 ±2°（PRD 允许 ±4°，这里克制地只取一半）；停下后用弹簧回正。正文不做形变。
- **M13 页脚幕布**：页脚固定在内容下层，正文滚走时像一张印好的纸被揭起。保留现有的 LUNTRIX 字母升起动画。
- **长列表**：用 `content-visibility: auto`。
- **锚点**：用 `scroll-margin-top` 避开粘性顶栏。

### 4.9 图像管线与生成式封面

- **生成式「排印封面」**（解决「文章没有封面」的问题）：
  - 由 slug 确定性生成：期号大字、标题排版、标签、文章强调色，加上网点或几何纹样。
  - 在服务端输出 SVG，客户端零 JS。
  - 5 种 `layout_variant` 各有一种构图。
  - 同一个生成器在 Nitro 路由里输出 OG 分享图（1200×630，带缓存）。
- **真实封面**：
  - AVIF / WebP + srcset，预留宽高比。
  - 占位图用「主色 + 网点」，加载完成后原图以墨色晕染的方式显现。
- **M3 WebGL**（桌面高档和中档设备）：
  - 悬停时出现墨水晕染位移，加上套色错位（代替通用的 RGB 分离效果）；滚动时平面按速度轻微弯曲。
  - 用 OGL 或手写 WebGL。
  - **全页共享一个 canvas** 渲染所有可见封面，不要每张图开一个 WebGL context。
  - 低档设备用 CSS 降级。

### 4.10 加载态、空状态、错误态与文案

- **加载**：用「校样」骨架——发丝线加浅网点，不用灰色圆角块。`NuxtLoadingIndicator` 改成顶部一条走纸墨线。
- **空状态**：每个栏目一句编辑口吻的文案，配一个小的排印图形。
- **错误**：已有的 Erratum 语境延伸到 500、离线和局部接口失败。
- **乐观更新**：点赞等操作失败时回滚，并给出提示（B07）。
- **文案即设计**：按钮、提示、空状态、错误信息统一用刊物的口吻。术语全站一致：特稿、专栏、期号、合订本、校样。

## 5. 逐页升级

每个页面都按三部分写：**主角**（一个签名动效）、**升级**、**必修**（复核后仍存在的缺陷）。

### 5.1 首页 `/` · 无限画布

**主角：M5 可变字体标题。** 「Liquid Editorial」每个字符的 `wght` 随与光标的距离变化，越近越粗，像铅字受压；`SOFT` 随滚动速度变化。拖拽画布时，标题像水印一样轻微反向位移。

**升级：**

- 卡片使用生成式封面的缩略图。
- 悬停某张卡片时，其余卡片透明度降到 0.4（PRD 5.1）。
- 拖拽时卡片按速度轻微缩放并做透视倾斜。
- 筛选时用 Flip 重排卡片，而不是简单变淡。
- 支持滚轮和触控板平移。
- 加入坐标读数和小地图，作为「套准坐标」。

**开场 M1：**

- 站名逐字压印（`wght` 200→800），计数 000→100，然后朱砂遮罩上揭，总时长 ≤ 1.6 秒。
- 可以点击或按任意键跳过。
- 禁用 JS 时不显示遮罩。

**必修：**

- B37：景深系数和取模叠加，拖动后卡片会漂移并互相重叠。
- B37：卡片压住中央标题。
- B37：空闲 3 秒后画布一直自动漂移，违反「有因果」原则。
- B37：SSR 没有输出列表视图的完整 HTML，影响 SEO。
- B38：360px 宽度下底部控制条溢出。

### 5.2 文章索引 `/posts`

**主角：** 悬停条目时，该文的生成式封面跟随光标浮现，带惯性和轻微倾斜，以墨色晕开的方式出现。

**升级：**

- 年份竖排，并且在滚动时 sticky。
- 切换筛选胶囊时，列表用 Flip 重排。

**必修：**

- B44：置顶文章没有任何标识，看起来像排序错误。
- B44：悬停用 `padding-left` 做动画，会触发重排。

### 5.3 文章详情 `/posts/:slug`（最高优先级）

**主角：** 五种 `layout_variant` 是**完全不同的构图**，而不只是改几个参数：

| 模板 | 构图 |
| --- | --- |
| `standard` | 经典特稿：标题跨 1–10 栏，元信息竖排在 11–12 栏 |
| `wide` | 宽版图解：正文保持 680px，图和代码可以破栏到 1080 或 1440px |
| `immersive` | 全屏头图或生成式封面，标题压在图上；滚动时头图以「揭版」方式移走 |
| `essay` | 随笔：首字下沉、窄栏、更大行距、没有侧栏，整体安静 |
| `showcase` | 陈列：M9 横向滚动章节（用 ScrollTrigger pin） |

**阅读体验：**

- 宽屏下脚注变成页边旁注；悬停时用一条发丝引线连到正文里的引用位置。
- `TocScale` 增加「已读填充」，并显示当前章节标题。
- 阅读进度改成页面顶端的一条墨线。
- 阅读设置（字号、字体、行宽、连字）在 ≤ 1024px 时也要有入口（B43）。
- 正文列和评论列的左边缘对齐（B43：1440 宽度下相差约 48px）。

**代码块：**

- 补齐：行号、`code-group` 多文件标签页、自动换行开关、横向溢出时两端渐隐、文件类型图标。
- 修复终端块每行之间多出的空行（B43）。
- 复制后按钮文字翻转成「已复制」（M15）。

**图片：** 点击后用共享元素动画放大到灯箱，支持手势缩放和 Esc 关闭。

**互动：**

- 点赞改为**朱砂印章**：按下时，一枚「阅」字方印带着轻微旋转盖在按钮上，墨色有纸纹的不均匀感；计数像号码机一样滚动。
- 分享时附带生成式 OG 卡片。
- 文末加一页「版权页」（colophon）：字数、阅读时长、首发与修订日期、授权协议、本期编号。

### 5.4 专栏 `/series` 与 `/series/:slug`

**主角：书脊。** 每个专栏是书架上的一本书：竖排书名、卷号，书的厚度按章节数计算；悬停时这本书从书架上抽出一点。

**升级：**

- 详情页做成装订线加目录页：引导点（leader dots）+ 页码。
- 读过的章节打一个朱砂小勾（记录在本地）。

### 5.5 项目 `/projects` 与 `/projects/:slug`

**主角：字模样张。** 每个项目像字体样张一样展示：

- 超大号的项目名。
- 语言颜色作为专色。
- Star、Issue 数用等宽数字滚动显示。
- 悬停时，卡片背景的网点密度随光标位置变化。

**必修：** 项目详情页仍在客户端运行 Shiki，首屏 JS 约 680 KB gzip（B05）。改为和文章页一样由 Nitro 服务端渲染。

### 5.6 今日所学 `/til`

**主角：终端打字。** 条目进入视口时，命令按真实的打字节奏打出来。

**升级：**

### 5.7 归档 `/archive`

## 7. 「丝滑」的工程定义

| 方面 | 要求 |
| --- | --- |
| 响应 | 任何点击或按键在 100 ms 内必须有视觉回应（按压态），哪怕数据还在加载 |
| 中断 | 所有状态动画都能从当前值反向，不跳变、不排队 |
| 节奏 | 进入用 out 缓动，离开用 in 缓动，离开更快；同一组元素之间的错峰 ≤ 60 ms，整组总错峰 ≤ 400 ms |
| 布局稳定 | 读写分离：先批量读取几何，再批量写入；缓存几何信息，配合 ResizeObserver 更新；字体和图片加载不推动布局 |
| 合成层 | `will-change` 只在动画期间添加；`backdrop-filter` 只用于顶栏和少数浮层，滚动时不叠加多层 |
| 预取 | 鼠标悬停链接 100 ms 后，预取目标页的数据和封面（PRD 11.1） |
| 长任务 | 拆分重计算，用 `scheduler.yield` 或 `requestIdleCallback` |
| 帧率无关 | 所有物理效果都按时间步长计算 |

## 10. 明确不要做的事

- 不要推翻 Liquid Editorial，另起一套新风格。
- 视觉风格上：
  - 不要组件库外观、泛滥的玻璃拟态、霓虹、大面积渐变、3D 插画。
  - 不要背景音乐或自动播放的音效。
- 动效上：
  - 不要无因果的循环动画，比如呼吸灯、无限漂移、旋转的 Logo。表达状态的除外，比如项目「活跃」的脉冲点。
  - 不要为了效果牺牲正文阅读。
- 不要把 three.js、TresJS、matter.js、CodeMirror 打进首屏。
- 不要只打磨首页。栏目页、空状态、错误态、后台同等对待。

**最后用一句话自检：** 如果把站名遮住，访客还能认出这是谁的刊物吗？
