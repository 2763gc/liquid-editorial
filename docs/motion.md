# 动效系统设计与参数规范 (Motion System Specification)

本项目核心卖点为「电影级动效」，遵循 PRD 第 3 节规范：所有动效稳定 60fps，有物理，可被打断，可被关闭。

---

## 1. 动效原则

1. **有因果**：每个动效源自用户动作或内容状态变化，不做无意义的循环旋转。
2. **有物理**：采用惯性、阻尼与弹性；拖拽松手后继承速度继续滑行。
3. **有层次**：主元素先动，次要元素错峰跟随。
4. **可中断**：新交互能随时打断正在播放的动画并平滑接管，不排队等待。
5. **可关闭**：遵循系统 `prefers-reduced-motion`，并提供站内「减弱动效」开关。

## 2. 动效 Token 映射

| Token | CSS 值 | GSAP CustomEase / 时长 | 用途 |
| :--- | :--- | :--- | :--- |
| `--ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | `CustomEase.create("outExpo", "0.16, 1, 0.3, 1")` | 元素进入、卡片弹入 |
| `--ease-in-out-quart` | `cubic-bezier(0.76, 0, 0.24, 1)` | `CustomEase.create("inOutQuart", "0.76, 0, 0.24, 1")` | 页面转场、遮罩滑移 |
| `--ease-out-back` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | `CustomEase.create("outBack", "0.34, 1.56, 0.64, 1")` | 磁吸与按键回弹 |
| `--dur-micro` | `180ms` | `0.18s` | 悬停、光标缩放、按压 |
| `--dur-sm` | `350ms` | `0.35s` | 折叠展开、Tab 切换 |
| `--dur-md` | `700ms` | `0.7s` | 遮罩揭示、文字逐行滑入 |
| `--dur-page` | `900ms` | `0.9s` | 路由页面转场 |
| `--stagger-char` | `40ms` | `0.04s` | 字符序贯错峰 |
| `--stagger-list` | `60ms` | `0.06s` | 列表项错峰 |

## 3. 签名动效清单 (P0 核心)

- **M1 开场序幕**: 站名逐字压印 (wght 200→800) + 000→100 计数 + 强调色遮罩上揭。
- **M2 共享元素转场**: 卡片封面经 GSAP Flip 无缝展开至文章头图，标题同步上移。
- **M3 WebGL 图像形变**: TresJS 渲染图像平面，悬停噪声驱动液态位移，滚动时按速度纵向微弯曲。
- **M4 文字揭示**: SplitText 按行拆解，`overflow: hidden` 容器内 `yPercent: 110 -> 0`。
- **M6 上下文光标**: 8px 圆点 + 40px 跟随圆环（插值 lerp 0.15），悬停卡片变为「阅读」，画布变为「拖拽」。
- **M7 磁吸按钮**: 光标 80px 范围吸引位移最大 12px，弹性回弹。
- **M10 四时光照系统**: 晨 (05-10h)、昼 (10-17h)、暮 (17-20h)、夜 (20-05h) 本地时间平滑过渡。
- **M11 全屏菜单**: 圆形 clip-path 扩散展平，超大标题悬停背景浮现漂浮封面。
- **M12 章节刻度尺**: 文章右侧竖向标尺，随滚动高亮当前章节并支持平滑滚动定位。
- **M15 微交互集合**: 点赞粒子迸发、复制代码翻转为「已复制」、发丝线下划线展开。
